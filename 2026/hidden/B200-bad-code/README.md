## Summary

An off-board channel someone left open on the CTF domain. It is not listed anywhere; you reach it by noticing a signature that keeps turning up in other challenges. Whoever is on the other end signs their work, always has, and would rather talk than hand you anything out loud.

## Skills

- following a breadcrumb across challenges to an unlisted page
- reading and deobfuscating page JavaScript
- using the browser console as the intended path

## Tools that help

a web browser and its developer console.
