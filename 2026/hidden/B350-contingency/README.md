## Summary

A sealed failover protocol, a page that answers only when it is found. The Machine kept it, and should not have. The word for it keeps surfacing wherever things go wrong across the event. Follow it, put the scrambled record in order, and read what it was really protecting.

## Skills

- following a breadcrumb trail across challenges
- reading a scrambled table and restoring its order
- hex-to-ASCII decoding to recover a recovery key

## Tools that help

a web browser; any hex-to-ASCII decoder.
