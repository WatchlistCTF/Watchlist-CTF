# R150: Ghosts

**Category:** Recon · **Points:** 150

```text
[ FILE REF: S1E2 "GHOSTS" // NORTHERN LIGHTS RELAY - DECOMMISSIONED, STILL LIT ]

Northern Lights ran more nodes than anyone will admit. Most were
torn down. The records were pulled, the links cut, the names
scrubbed from every directory they controlled.

They forgot the one thing they never controlled.

Every node that spoke securely had to ask a public authority for a
certificate - and every such request is witnessed, then written into
a ledger that anyone can read and no one can erase. One of those
nodes is a ghost now: unlisted, unlinked, unguessable.

But the ledger still remembers its name.

  Start here:   northernlights.gg

Read the record of what was issued. Find the relay that should be
dark. Then knock.

  - THE MACHINE
```
