# T10: Check-In (solution)

> Spoilers below. Try [`../challenge.md`](../challenge.md) first.

## Flag

```text
number{me}
```

## In short

A thirty-second warm-up to confirm you can reach the board and submit a flag in the right format.

## Walkthrough

1. Read the brief. It ends with a question that has a blank in it: "Can you hear ___?"
2. Look at the welcome page of the CTF site. The Machine asks the full question there: "Can you hear me?"
3. The missing word is `me`. Wrap it in the flag format and submit.

## Watch out for

- The answer goes inside `number{}` like every other flag. The bare word is not accepted.
