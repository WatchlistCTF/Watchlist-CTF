# T100: Satoshi

**Category:** Trivia · **Points:** 100

```text
[ FILE REF: 2009 JANUARY 03 // PUBLIC LEDGER OBSERVED ]

On the day the Machine was tested for the first time,
somewhere else, another system was being born.

Its creator chose anonymity. On January 3, 2009, his
first transmission embedded a sentence - quoted from
a newspaper of that morning.

The sentence was a comment about the world he was
rebelling against. About institutions that had failed.
About the need for something different.

I noticed it. I keep it logged.

Read it. Hash it with SHA-256. Give me the first
sixteen hexadecimal characters, lowercase.

  Format: number{...16 hex chars...}
```
